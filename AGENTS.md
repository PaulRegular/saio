# SAIO curation

Read PROTOCOL.md and DATABASE_STRUCTURE.md before editing source records. Preserve source units, dimensions, provenance, and completeness statuses. Source curation must run independently of downstream modelling software. Keep downstream instructions, model comparisons and project history in the consuming project, not here. Keep cached authoritative files under ignored source_cache/ and maintain their retrieval manifests under provenance/. Maintain one release line on main. For a validated database milestone, commit the release manifest, reviewed importers, source manifests, correction notes and tests. Build the consolidated CSV tables locally and package them as compressed release assets. Keep intermediate imports and generated tables in the working copy. See [Batch commits and snapshots](PROTOCOL.md#batch-commits-and-snapshots). Do not publish or push without authorization.
