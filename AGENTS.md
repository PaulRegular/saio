# SAIO curation

Read PROTOCOL.md and DATABASE_STRUCTURE.md before editing source records. Preserve source units, dimensions, provenance, and completeness statuses. Source curation must run independently of downstream modelling software. Keep downstream instructions, model comparisons and project history in the consuming project, not here. Keep cached authoritative files under ignored source_cache/ and maintain their retrieval manifests under provenance/. Commit the five consolidated database tables only at major milestones, with one data commit per validated batch. Keep intermediate stock imports, table revisions and test runs in the working copy. Commit reviewed importers, source manifests, correction notes and tests in logical steps without staging the consolidated tables. See [Batch commits and snapshots](PROTOCOL.md#batch-commits-and-snapshots). Do not publish or push without authorization.
