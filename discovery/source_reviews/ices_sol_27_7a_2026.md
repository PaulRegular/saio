# Irish Sea sole: 2026 discovery review

ICES `sol.27.7a` is *Solea solea* in the Irish Sea. The canonical sole records describe other areas; none identifies division 7.a. The [2026 WGCSE report](https://doi.org/10.17895/ices.pub.32625759), section 19, presents a SAM assessment with 1970-2025 data and ages 1-10+. The official 2026 assessment graph identifies advice key 22641; the cross-check below corroborates the working-group run.

The report provides catch numbers-at-age in thousands (Table 19.2), catch and stock weights-at-age in kg (Tables 19.3 and 19.5), and tuning series (Table 19.9). Its model uses the UK(E&W)-BTS-Q3 survey at ages 1-7, 1988-2025, excluding the missing 2020 survey; its specified survey interval is 0.75-0.85 of a year. A Belgian commercial biomass index is also used. Catch age 1 before 2003 is set missing for model fitting even though the printed catch table contains entries. The report prints a fixed age-specific mortality vector for ages 1-10+ and describes a revised, time-varying survey-derived maturity ogive. Tables 19.13-19.16 report fitted F and N at age, SSB-at-age and annual summaries. Verify each table's units, missingness and interval definitions against the production run during curation.

The [pinned ICES code repository](https://github.com/ices-advice/2026_sol.27.7a/tree/bff4518e75378685700c849a24c5ba9c86e5a575/2026_sol.27.7a_assessment) confirms that the model reads a time-varying `mo.txt` maturity input and documents how it prepares the SAM data. The cached repository archive contains the scripts, but not the numerical files under `boot/initial/data/` or a fitted object. The report shows maturity in figures, not as a recoverable numerical matrix. Screening is complete; eligibility remains unresolved until the revised production maturity values and run-matched input files are recovered. Do not infer maturity from fitted output or substitute an older ogive.
