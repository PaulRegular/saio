# Assessment source reviews

Keep official run identity, source definitions, units, transformations, verification and unresolved source gaps here. Source curation and completeness do not depend on a successful downstream model. Analysis-specific model settings, initialization attempts, diagnostics and comparisons belong with the analysis that uses them.

Retain distinct historical runs under explicit assessment identifiers. New recoveries take precedence over superseded row counts or missing-data claims; do not mix observations or outputs from different runs.
